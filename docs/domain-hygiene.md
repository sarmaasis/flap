# Domain / brand hygiene

| Host | Status | Action |
|------|--------|--------|
| `useflap.online` | Canonical live product | Keep sole public brand URL |
| `useflap.com` | Not Flap (DNS fail / unowned) | Buy + 301 → `useflap.online` **or** stop mentioning |
| `flapmail.xyz` | DNS fail | Park/redirect if owned; else ignore |
| `inlet.email` | Broken / legacy | Do not cite in SEO copy |
| `useinlet.com` | Resolves to unrelated site | Never link; disavow if indexed |

Public copy, README, and llms files must only promote **useflap.online**.
