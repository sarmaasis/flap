# Security policy

## Supported version

Security fixes are applied to the latest version on the default branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use the repository's private vulnerability-reporting feature, or contact the maintainer through their GitHub profile, with:

- a clear description of the issue;
- the affected version or commit;
- steps to reproduce it; and
- any suggested mitigation, if available.

Please allow a reasonable amount of time for acknowledgement and remediation before public disclosure.

## Deployment responsibility

Flap is operated in your own Cloudflare account. Keep your Cloudflare account, Worker URL, domain DNS, and administrator credentials secure; review Cloudflare access controls and regularly back up D1 and R2 data.
